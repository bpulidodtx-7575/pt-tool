## Context

What is true today, and what forced a decision. Facts and constraints — not the
decision itself. If a number drove the choice, put the number here.

## Decision

What was chosen, stated so someone can act on it without reading the rest.

## Consequences

What this makes easy, what it makes harder, and what is now owed. Be specific
about the costs; an ADR that lists only benefits is an advertisement, not a record.

## Alternatives considered

What else was on the table and the actual reason it lost. "It was worse" is not
a reason.
